2. Datos que tratamos

Cuando utilizas un formulario podemos tratar tu nombre, empresa, correo electrónico, teléfono, página web y la información que incluyas sobre tu consulta. El servidor también puede generar registros técnicos imprescindibles para la seguridad y el diagnóstico de errores.

3. Finalidad y base jurídica

Tratamos los datos para atender tu consulta, valorar tu caso y mantener las comunicaciones necesarias antes de una posible relación profesional. La base jurídica es tu consentimiento y, cuando solicitas una propuesta o servicio, la aplicación de medidas precontractuales a petición tuya.

No utilizaremos los datos enviados mediante estos formularios para darte de alta automáticamente en comunicaciones comerciales.

4. Conservación

Conservaremos los datos durante el tiempo necesario para responder y gestionar la posible relación profesional. Después podrán mantenerse bloqueados durante los plazos exigidos para atender obligaciones legales o posibles responsabilidades.

5. Destinatarios

No vendemos ni cedemos tus datos. Podrán acceder a ellos proveedores que sean necesarios para prestar el servicio —como alojamiento y correo— bajo las obligaciones correspondientes, y las administraciones públicas cuando exista una obligación legal.

6. Derechos

Puedes solicitar el acceso, rectificación, supresión, oposición, limitación o portabilidad de tus datos, así como retirar tu consentimiento, escribiendo a info@lallavedetupyme.com. Incluye información suficiente para identificar tu solicitud.

También puedes presentar una reclamación ante la Agencia Española de Protección de Datos en aepd.es.

7. Analítica

Si aceptas las cookies de analítica, utilizamos Google Analytics para medir el uso del sitio y las solicitudes confirmadas. Puedes rechazar esta medición y seguir utilizando la web. Encontrarás el detalle y podrás revisar tu elección en la política de cookies.

8. Decisiones automatizadas

No tomamos decisiones automatizadas ni elaboramos perfiles a partir de los datos enviados en los formularios de esta web.
